# Tab频道页配置

> 本文描述运营后台“营销管理 > Tab频道页配置”的产品信息架构与关键操作流程。结构图按页面工作区拆分，流程图仅描述运营操作、配置校验与状态判断，不包含研发实现逻辑。

### 1.2 组件型页面工作区结构

适用页面：首页 - 功能区营销、福利页 - 信息流、柚子街 - 限时抢购、我 - 信息流。

```mermaid
flowchart TB
  A[组件型页面工作区] --> B[工作区头部]
  A --> C[主体编辑区]

  B --> B1[页面名称与说明]
  B --> B2[查看配置列表]
  B --> B3[最近编辑]
  B3 --> B31[查看更多]
  B2 --> B21[已保存配置列表]
  B21 --> B211[查看配置详情]
  B21 --> B212[选择配置进入编辑]

  C --> L[左侧：组件栏]
  C --> P[中间：页面预览栏]
  C --> R[右侧：配置栏]

  L --> L1[组件类型清单]
  L1 --> L11[按当前页面提供的组件类型]
  L --> L2[选择组件]
  L --> L3[拖入页面预览区新增组件]

  P --> P1[所见即所得页面预览]
  P1 --> P11[展示已保存与当前新增组件]
  P --> P2[点击选中已添加组件]
  P2 --> R2
  P --> P3[拖动调整组件排序]
  P3 --> P31[预览顺序实时变化]

  R --> R1[未选择组件：空状态]
  R --> R2[已选择组件：当前组件配置]
  R2 --> R21[基础信息]
  R2 --> R22[素材或功能配置]
  R2 --> R23[适用时：定向信息]
  R2 --> R24[适用时：测试计划]
  R2 --> R25[必填项校验与错误提示]
  R --> R3[编辑已保存组件]
  R --> R4[保存当前组件]
  R4 --> R41[保存成功后更新预览与配置列表]
  R --> R5[取消当前未保存修改]
  R --> R6[移除未保存新增组件]

  R2 --> R26[首页功能金刚区：展位配置]
  R26 --> R261[保存展位配置]
  R261 --> R4
```

**组件型页面结构规则**

1. 页面工作区固定由组件栏、页面预览栏、配置栏构成；组件栏负责添加，预览栏负责所见即所得与排序，配置栏负责当前选中对象的编辑和保存。
2. `查看配置列表`用于查看已保存配置；`最近编辑`用于快速回到最近维护的对象，超过当前展示范围时通过`查看更多`进入完整列表。
3. 保存是对象级操作：保存当前组件，或在功能金刚区场景先保存展位配置、再保存功能金刚区组件；不在此页面定义统一的“整页保存”动作。
4. 删除或移除仅针对当前未保存的新增组件；已保存对象需进入编辑路径维护。

**Tab型页面结构规则**

1. `查看Tab列表`是集中维护入口，包含筛选、搜索、新增、编辑与展位管理；展位管理内继续维护展位列表及添加、编辑、复制等操作。
2. 预览栏以当前 Tab 为上下文。运营人员先选择或新建 Tab，再查看其资源位、添加资源位及调整资源位顺序。
3. 新增 Tab 必须完成必填配置并保存，左侧组件栏才允许向该 Tab 拖入资源位。
4. 右侧配置栏随选择对象切换：选中 Tab 时维护 Tab；选中资源位时维护资源位。两者均按当前对象保存，不定义统一的“保存整页”按钮。

## 2. 产品流程图

### 2.1 进入频道页与页面类型分流

```mermaid
flowchart TD
  A[进入营销管理] --> B[进入Tab频道页配置]
  B --> C[选择底部 Tab]
  C --> D[选择页面子导航]
  D --> E{页面工作区类型}
  E -->|组件型编辑器| F[进入组件型页面配置流程]
  E -->|Tab型编辑器| G[进入Tab型信息流配置流程]
  E -->|列表型编辑器| H[进入弹窗营销配置流程]
```

**流程说明**：频道选择决定当前可维护页面；页面子导航决定工作区类型与后续操作路径。运营人员可通过`查看配置列表`、`查看Tab列表`、`最近编辑`或`查看更多`快速定位已保存对象，但其后仍进入对应对象的编辑流程。

### 2.2 Tab型信息流配置流程

```mermaid
flowchart TD
  A[进入Tab型信息流工作区] --> B{选择操作入口}
  B -->|查看Tab列表| C[搜索、筛选或选择已有Tab]
  B -->|新增Tab| D[填写Tab基本信息]
  B -->|预览区选择Tab| E[选中当前Tab]

  C --> E
  D --> D1[配置商品流、定向信息和测试计划]
  D1 --> D2{Tab必填项是否完整}
  D2 -->|否| D3[提示第一个未填写字段]
  D3 --> D
  D2 -->|是| D4[保存当前Tab]
  D4 --> E

  E --> F{当前Tab是否已保存}
  F -->|否| G[继续完善并保存当前Tab]
  G --> D
  F -->|是| H{资源位操作}
  H -->|从组件栏拖入| I[向当前Tab添加资源位]
  H -->|从预览区选择| J[选择已有资源位]
  H -->|调整顺序| K[拖动资源位排序]

  I --> L[配置资源位基础信息、素材或功能]
  J --> L
  L --> L1[配置定向信息和测试计划]
  L1 --> L2{资源位必填项是否完整}
  L2 -->|否| L3[提示第一个未填写字段]
  L3 --> L
  L2 -->|是| L4[保存当前资源位]
  L4 --> M[在预览区查看当前Tab效果]
  K --> M
  M --> N{继续维护当前Tab吗}
  N -->|是| H
  N -->|否| O[返回页面或切换其他Tab]

  O --> P{是否存在未保存修改}
  P -->|是| Q[选择放弃修改或继续编辑]
  Q -->|放弃修改| R[离开当前编辑]
  Q -->|继续编辑| H
  P -->|否| R
```

**关键规则**

1. 新增 Tab 先完成并保存 Tab 配置，再向该 Tab 添加资源位。
2. Tab 与资源位分别独立校验、独立保存；保存成功后，当前对象的内容成为可在列表和预览中继续维护的配置。
3. 排序在当前 Tab 的预览区完成；排序后继续按照当前页面提供的保存动作提交对应对象。
4. 离开当前编辑且存在未保存修改时，运营人员需选择放弃修改或继续编辑。

### 2.3 组件型页面配置流程

```mermaid
flowchart TD
  A[进入组件型页面工作区] --> B{选择操作入口}
  B -->|查看配置列表或最近编辑| C[选择已保存组件]
  B -->|组件栏拖入| D[向页面预览区添加组件]
  B -->|预览区点击| E[选择页面内组件]

  C --> F[进入当前组件配置]
  D --> F
  E --> F
  F --> G[填写基础信息、素材或功能配置]
  G --> H[按组件需要配置定向信息和测试计划]
  H --> I{当前组件必填项是否完整}
  I -->|否| J[提示第一个未填写字段]
  J --> G
  I -->|是| K{是否为功能金刚区展位配置}
  K -->|是| L[保存当前展位配置]
  L --> M[保存功能金刚区组件]
  K -->|否| N[保存当前组件]
  M --> O[在页面预览区查看效果]
  N --> O

  O --> P{是否调整页面内组件顺序}
  P -->|是| Q[拖动组件排序]
  Q --> R[继续维护当前组件或其他组件]
  P -->|否| R
  R --> S{是否继续编辑}
  S -->|是| B
  S -->|否| T{是否存在未保存修改}
  T -->|是| U[选择放弃修改或继续编辑]
  U -->|放弃修改| V[离开当前编辑]
  U -->|继续编辑| F
  T -->|否| V
```

**关键规则**

1. 可从组件栏新增、从配置列表或最近编辑进入已保存对象，也可直接从预览区选择页面内组件。
2. 保存是当前组件级操作。功能金刚区存在展位配置时，应先保存展位配置，再保存功能金刚区组件。
3. 未保存的新增组件可从预览区移除；已保存组件通过选择组件后进入编辑流程维护。
4. 组件排序以预览区内的实际顺序为准，操作后继续执行当前对象对应的保存动作。

### 2.4 打卡成功弹窗营销配置流程

```mermaid
flowchart TD
  A[进入打卡成功弹窗营销配置列表] --> B{选择操作}
  B -->|筛选或分页| C[查看配置记录]
  B -->|新增| D[新建弹窗营销配置]
  B -->|编辑| E[打开已有配置]
  B -->|复制| F[复制已有配置后进入编辑]

  C --> B
  D --> G[配置基本信息、功能信息、定向信息和测试计划]
  E --> G
  F --> G
  G --> H[查看效果预览]
  H --> I{必填项是否完整}
  I -->|否| J[提示第一个未填写字段]
  J --> G
  I -->|是| K[保存当前弹窗营销配置]
  K --> L[返回并刷新配置列表]
  L --> B
```

**关键规则**

1. 新增、编辑、复制均以单条弹窗营销配置为操作对象。
2. 效果预览用于运营确认；保存前完成当前配置的必填校验，保存成功后列表展示最新结果。
3. 本流程不定义与其他频道页共用的整体发布或页面级保存步骤。
