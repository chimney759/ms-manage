# 可视化编辑框架

可视化编辑框架是后台可视化组件配置页面共用的编辑生命周期服务，代码 API 保持为 `window.EditSession`。

## 适用范围

- 首页-功能区营销
- 首页-信息流营销
- 福利页-信息流营销
- 柚子街-信息流
- 柚子街-限时抢购
- 我-信息流

以上页面使用统一的页面框架、组件编辑状态、组件保存、页面保存、撤销和离开确认逻辑。

## 不适用范围

以筛选、表格、行级新增、编辑、复制为主的列表管理页面不接入本框架，例如福利页下的打卡功能营销配置。此类页面保留原有列表操作方式。

## 统一约定

1. 进入组件配置时开始编辑状态。
2. 配置单元存在修改时，必须先保存配置单元，才能保存页面。首页信息流营销以 Tab 为配置单元，操作名称为“保存Tab”。
3. 保存页面后，以当前状态作为页面已保存版本并退出编辑状态。
4. 撤销页面修改时，恢复到最近一次页面保存的版本。
5. 编辑中切换导航且页面存在未保存修改时，提示“当前编辑的内容未保存，是否仍然要关闭”。
