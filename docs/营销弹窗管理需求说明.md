# 营销弹窗管理需求说明

> 适用入口：`推广管理 > 营销弹窗管理`。本说明适用于首页（Home）、福利页（第2 Tab）、柚子街（第3 Tab）及我（Mine）四个频道的营销弹窗配置列表。

## 1. 筛选项说明

| 筛选项 | 控件类型 | 默认值 | 字段定义 | 筛选规则与限制说明 |
| --- | --- | --- | --- | --- |
| 弹窗归属 | 频道切换 | 首页（Home） | 指定当前维护的营销弹窗所属频道。可选：首页、福利页、柚子街、我。 | 频道为数据隔离维度。切换频道后，所属位置、筛选结果、列表数据以及添加、修改、复制操作均切换至该频道；不同频道的配置不可混合展示。 |
| APP | 只读文本 | 美柚省钱 App | 当前配置所属应用。 | 固定展示，不支持筛选或修改。 |
| 所属位置 | 只读文本 | 当前频道 | 当前列表所属的页面位置，格式为“中文频道名（频道标识）”，如“首页（Home）”。 | 由弹窗归属联动产生，不支持手动修改。 |
| 活动名称 | 文本输入框 | 空 | 营销弹窗的后台记录名称。 | 支持模糊匹配；输入后可点击“搜索”查看结果。仅匹配当前频道下已保存的配置。 |
| 状态 | 下拉复选 | 上线中、待上线、已下线均选中 | 营销弹窗当前展示状态。可选：上线中、待上线、已下线。 | 支持多选和取消选择；按所选状态组合过滤当前频道列表。未选择任何状态时，列表不展示数据。点击下拉框外部或按 Esc 收起下拉框，不改变已选条件。 |
| 搜索 | 按钮 | - | 按当前活动名称和状态条件查询列表。 | 仅刷新当前频道下符合条件的已保存配置；不清空既有筛选条件。 |

## 2. 列表说明

### 2.1 列表展示规则

1. 列表仅展示当前频道下**已保存**的营销弹窗配置；新增、复制或修改过程中未保存的内容不进入列表。
2. 列表默认按当前数据顺序展示；用户点击支持排序的列头后，可在升序和降序之间切换。
3. 无符合条件的数据时，展示空状态提示“当前导航下暂无已保存的营销弹窗配置”。
4. 列表底部展示当前筛选结果条数。

### 2.2 列表字段定义

| 字段 | 展示形式 | 字段定义 | 取值/展示规则 | 交互与限制说明 |
| --- | --- | --- | --- | --- |
| 弹窗 ID | 文本 | 营销弹窗的唯一标识。 | 展示该条已保存配置的弹窗 ID。 | 支持排序。 |
| 排序级别 | 数字 | 用于定义同一频道内营销弹窗的展示优先级。 | 展示编辑页填写的排序级别；数值越大，展示优先级越高。 | 支持排序；鼠标移入字段说明可查看“数值越大，弹窗越靠前展示”。 |
| 活动名称 | 文本 | 营销弹窗的后台记录名称，用户端不可见。 | 展示保存的活动名称。 | 支持排序；与“活动名称”筛选项联动。 |
| 弹窗主图 | 图片缩略图 | 用户端营销弹窗的主视觉图片。 | 已配置时展示缩略图；未配置时展示“-”。 | 鼠标移入缩略图时放大预览完整图片；预览不改变图片内容。 |
| 所属位置 | 文本 | 营销弹窗所在频道。 | 展示首页、福利页、柚子街或我。 | 支持排序；与当前弹窗归属保持一致。 |
| 指定人群 | 文本 | 弹窗定向信息的汇总展示。 | 展示已配置的指定人群、定制人群等人群条件；未配置时展示“-”。 | 支持排序。 |
| 推送频次 | 文本 | 单个用户可收到该弹窗的次数限制。 | 格式为“每人每日 N 次；总共 N 次”。 | 不支持列表内编辑。 |
| 重复展示 | 文本 | 弹窗在每日中的重复展示规则。 | 全天时展示“每天重复，全天展示”；指定时段时展示“每天重复，开始时间 - 结束时间展示”。 | 不支持列表内编辑。 |
| 上下线时间 | 文本 | 营销弹窗的生效时间区间。 | 展示开始时间至结束时间；未完整配置时展示“-”。 | 支持排序。 |
| 状态 | 状态标签 | 当前营销弹窗的展示状态。 | 可展示：上线中、待上线、已下线。 | 支持排序；与状态筛选项联动。 |
| 创建人 | 文本 | 首次创建该配置的操作人。 | 展示创建人信息。 | 支持排序。 |
| 创建时间 | 时间文本 | 首次保存该配置的时间。 | 按系统时间格式展示。 | 支持排序。 |
| 最新编辑人 | 文本 | 最近一次保存该配置的操作人。 | 展示最新编辑人信息。 | 支持排序。 |
| 最后更新时间 | 时间文本 | 最近一次保存的时间。 | 按系统时间格式展示。 | 支持排序。 |
| 操作 | 文本按钮 | 对当前营销弹窗进行维护的入口。 | 包含“修改”“复制”。 | 点击操作仅作用于当前行，不影响其他配置。 |

## 3. 操作说明

### 3.1 添加弹窗

| 操作项 | 操作说明 | 结果与限制说明 |
| --- | --- | --- |
| 添加弹窗 | 在当前频道列表点击“添加弹窗”。 | 进入当前频道的全屏编辑工作区，保留左侧导航和弹窗归属频道切换；编辑页使用左侧返回，不提供右侧关闭入口。 |
| 填写配置 | 依次维护基础信息、跳转配置、素材信息、出站过程配置、Tab 提醒配置、定向信息、展示规则和测试计划。 | 活动名称、跳转配置、弹窗主图、平台版本、推送频次、重复展示、上下线时间及状态等必填内容需满足校验要求；测试计划按实际需要配置。 |
| 配置跳转 | 选择“页面跳转”或“自定义地址/协议”。 | 选择页面跳转时，必须选择目标页面；选择自定义地址/协议时，必须填写路由协议和地址/协议说明，并按需维护 PID、`skip_type`。仅展示当前跳转类型所需字段。 |
| 配置点击热区 | 在素材信息中添加、维护或移除热区。 | 可配置多个热区；每个热区独立维护名称、X/Y 坐标、宽、高和跳转协议。未配置热区时，主图整体作为默认点击区域。 |
| 保存 | 点击保存当前营销弹窗配置。 | 校验通过后，保存为当前频道的一条配置并返回当前频道列表；保存后才参与列表查询、排序与展示。 |

### 3.2 修改弹窗

| 操作项 | 操作说明 | 结果与限制说明 |
| --- | --- | --- |
| 修改 | 点击列表当前行的“修改”。 | 进入该营销弹窗所在频道的全屏编辑工作区，并带入已保存配置。 |
| 保存修改 | 调整配置后点击保存。 | 覆盖更新当前营销弹窗；列表中的活动名称、主图、定向信息、展示规则、状态及维护信息同步更新。 |
| 返回 | 点击编辑页左侧返回，或切换弹窗归属频道。 | 无未保存修改时直接离开编辑页；存在未保存修改时，需先确认“继续编辑”或“放弃修改”。选择放弃修改后，不保存本次改动。 |

### 3.3 复制弹窗

| 操作项 | 操作说明 | 结果与限制说明 |
| --- | --- | --- |
| 复制 | 点击列表当前行的“复制”。 | 进入当前频道的全屏编辑工作区，并带入被复制弹窗的配置内容，作为新的未保存草稿。 |
| 调整并保存 | 根据实际活动调整复制后的配置并保存。 | 保存成功后生成一条新的独立营销弹窗配置；不覆盖原配置。未保存前不进入列表。 |

### 3.4 保存校验与提示

| 场景 | 校验/提示规则 | 处理结果 |
| --- | --- | --- |
| 必填项缺失 | 保存时校验必填项及关联规则。 | 在页面约 2/3 处 Toast 提示首个未填写或不符合规则的字段，并停留在编辑页。 |
| 页面跳转未配置目标页面 | 跳转类型为“页面跳转”且未选择目标页面。 | 阻止保存，提示补充跳转配置。 |
| 自定义地址/协议未填写完整 | 跳转类型为“自定义地址/协议”且未填写路由协议或地址/协议说明。 | 阻止保存，提示补充跳转配置。 |
| 弹窗主图未上传 | 未配置弹窗主图。 | 阻止保存，提示补充弹窗主图。 |
| 展示规则不完整 | 未配置有效的平台版本、推送频次、展示时间段或上下线时间。 | 阻止保存，提示补充展示规则和上下线时间。 |
| 测试计划不完整 | 已启用测试计划但测试 UID 或有效时间未完整填写。 | 阻止保存，提示补充测试计划内容。 |
| 未保存修改离开页面 | 编辑页存在未保存修改且用户执行返回或切换频道。 | 二次确认。继续编辑则留在当前编辑页；放弃修改则退出且不保存本次变更。 |
